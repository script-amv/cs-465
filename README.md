## Working with this repository

The default branch is `module1`; it is retained to preserve the existing coursework workflow. Switch to a module branch to inspect that stage. On `module1`, use Node.js 20 or later, run `npm ci`, then `npm start`; open `http://localhost:3000`. Run `npm test` for the supplied server tests. Commands for other branches depend on their own package files.

## Run the site

1. Install dependencies with `npm install`.
2. Start the server with `npm start`.
3. Open `http://localhost:3000` in a browser.

The supplied static Travlr Getaways pages, stylesheet, and images are in `public/` and are served by Express.
